# TotalGram

<img src="logo.png" alt="" width="180">

Плагин файловой системы (WFX) для Total Commander: чаты Telegram видны как папки,
файлы из них скачиваются и загружаются обратно обычными F5 и F6. Отправка текстовых
сообщений не предусмотрена — только файлы.

История версий — в [TotalGram/CHANGELOG.md](TotalGram/CHANGELOG.md).

## Установка

**Автоматически:** нажмите Enter на `TotalGram-<версия>.zip` прямо в Total Commander —
он найдёт внутри `pluginst.inf` и предложит установку. В архиве лежат обе разрядности,
нужная выберется сама.

**Вручную:** положите `TotalGram.wfx` (32 бита) и `TotalGram.wfx64` (64 бита) в одну
папку, затем **Конфигурация → Настройка → Плагины → Плагины файловой системы →
Добавить** и выберите `TotalGram.wfx`.

## Первый запуск

Плагин ходит в Telegram с вашими собственными ключами API. Создайте их один раз на
[my.telegram.org](https://my.telegram.org) → *API development tools* и впишите в
`%APPDATA%\Igor Zviagintsev\TotalGram\config.ini`:

```ini
api_id=1234567
api_hash=0123456789abcdef0123456789abcdef
```

Откройте **Telegram** в сетевом окружении, нажмите Enter на `[+ Add account]` и
ответьте на вопросы: номер телефона, код из Telegram и пароль второго фактора, если он
включён. Аккаунтов можно добавить несколько, у каждого будет своя папка.

## Что внутри

```
\Telegram\
  <Аккаунт>\
    <Папка Telegram>\       папки, которые вы завели в Telegram
    All chats\
      Archived\             архивные чаты
      <Чат>\
        Media\              фото и видео
          Incoming\         то же самое, только полученное
          Outgoing\         то же самое, только отправленное
        Files\              документы
        Links\              ссылки из сообщений, в виде .url
        Music\              аудиозаписи
        Voice Messages\     голосовые
        GIF\                анимации
        All files\          всё перечисленное одним плоским списком
        Post 123\           по папке на пост (каналы, темы форумов)
          message.md        текст поста
        <Тема>\             темы форума, если они включены
    Saved Messages\         ярлык на «Избранное»
```

Личные чаты и обычные группы плоские: файлы лежат прямо в папке чата. У каналов и тем
форума — по папке на каждый пост.

`Incoming` и `Outgoing` есть в каждой папке с содержимым и в `All files`. Копировать
файлы в `Incoming` можно, но отправленное от вашего имени окажется в `Outgoing` —
плагин об этом предупредит.

`All files` существует потому, что ветвистый просмотр Total Commander (Ctrl+B) внутри
плагинов не работает: эта папка показывает все файлы чата одним списком.

## Отправка файлов

Копирование файла в чат отправляет его. Тип сообщения определяет папка назначения:

| Папка | Уйдёт как | Принимает |
|---|---|---|
| корень чата | по типу файла | что угодно |
| `Media` | фото или видео | изображения, видео |
| `Music` | аудиозапись | аудио |
| `Voice Messages` | голосовое | аудио |
| `GIF` | анимация | `.gif`, `.mp4`, `.webm` |
| `Files` | документ | что угодно |
| `Links` | ссылка сообщением | `.url` |

Файл, не подходящий папке по типу, отклоняется.

## Настройки

`%APPDATA%\Igor Zviagintsev\TotalGram\config.ini`

| Ключ | Что значит |
|---|---|
| `api_id`, `api_hash` | ключи Telegram API, обязательны |
| `max_items` | сколько старых записей дочитывать за один заход, по умолчанию `2000`; `0` — прочитать папку целиком сразу |
| `log_paths` | `1` пишет каждый запрос папки в FTP-лог, для диагностики |

Папки с содержимым спрашивают у Telegram по одному типу файлов за раз — так же работают
вкладки «Общие медиа» — поэтому достают историю за годы, а не только последние
сообщения.

Список каждой папки хранится в `%APPDATA%\Igor Zviagintsev\TotalGram\cache\`, и у
Telegram спрашивается только то, чего в кэше нет. Папка, которую не прочитать за один
заход, не обрезается навсегда: каждое открытие уходит глубже, пока история не кончится.
Уже дочитанная папка открывается одним запросом.

Кэш можно удалить, он соберётся заново. До этого момента файл, удалённый в Telegram,
остаётся в списке и не скачивается.

Сессии лежат в `%APPDATA%\Igor Zviagintsev\TotalGram\accounts\`. Удаление файла сессии
выходит из этого аккаунта.

## Требования

- Windows 10 или новее
- Total Commander 10.50 или новее
- аккаунт Telegram

Рантайм .NET не нужен: плагин скомпилирован в нативный код (Native AOT).

## Удаление

**Конфигурация → Настройка → Плагины → Плагины файловой системы**, выберите *Telegram*,
нажмите **Удалить**, затем удалите папку плагина и
`%APPDATA%\Igor Zviagintsev\TotalGram\`.

# Разработка

## Чем собирается

| Нужно | Зачем |
|---|---|
| [.NET 10 SDK](https://dotnet.microsoft.com/download) | целевая платформа `net10.0-windows` |
| Visual Studio Build Tools, workload **Desktop development with C++** | Native AOT компилирует через линкер MSVC |
| Python 3 (необязательно) | только для пересборки иконки и `logo.png` |

## От чего зависит код

| Зависимость | Где |
|---|---|
| [WTelegramClient](https://github.com/wiz0u/WTelegramClient) 4.4.8 | NuGet, единственный пакет |
| [WFX-SDK](https://github.com/ghisler/WFX-SDK) | сабмодуль, только документация — не компилируется |

## Сборка

```powershell
git clone --recurse-submodules git@github.com:inoyakaigor/totalgram.git
cd totalgram
.\build_package.ps1
```

На выходе `dist\TotalGram-<версия>.zip` — архив авто-установки, и россыпью те же
бинарники в `dist\release\`. Версия берётся из времени сборки: `yy.MM.dd.HHmm`.

Для цикла разработки хватит одной разрядности:

```powershell
dotnet publish TotalGram\TotalGram.csproj -c Release -r win-x86 --self-contained
```

Результат — `TotalGram\bin\Release\net10.0-windows\win-x86\native\TotalGram.dll`,
переименуйте в `TotalGram.wfx` там, где установлен плагин. Total Commander перед этим
закройте: он держит файл открытым.

### Две ловушки

**`vswhere.exe` не в PATH.** Линковка падает с `error MSB3073 ... link.exe`.
`build_package.ps1` подставляет путь сам, при ручной публикации сделайте так же:

```powershell
$env:PATH = "C:\Program Files (x86)\Microsoft Visual Studio\Installer;$env:PATH"
```

**Список экспортов для x86 ведётся руками.** На x86 линкер украшает stdcall-экспорты
(`_FsInit@16`), а Total Commander такие не принимает, поэтому цель `PatchDefFileForX86`
в `TotalGram.csproj` переписывает сгенерированный `.def` чистыми именами. Новый экспорт
надо добавить и туда, иначе в 32-битной сборке его просто не будет. Отдельно: Total
Commander решает, какие возможности есть у плагина, по **ANSI**-имени, хотя вызывает
Unicode-версию — `FsFindFirst` и `FsGetPreviewBitmap` существуют только поэтому.

## Что где лежит

```
TotalGram/          исходники плагина
  Core/             Telegram: аккаунты, чаты, поиск по типам, кэш листингов, передача файлов
  Wfx/              экспорты WFX и всё общение с Total Commander
  Models/           общие типы и имена виртуальных папок
WFX-SDK/            сабмодуль: официальный SDK Total Commander
build_package.ps1   сборка x86 + x64 и упаковка в zip
dist/               результат сборки, в git не хранится
```

## Правила репозитория

Каждая сборка получает запись в `TotalGram/CHANGELOG.md`: пишется под заголовком
`## Unreleased`, а `build_package.ps1` заменяет его на версию, которую собирает.
Подробнее — в [AGENTS.md](AGENTS.md), раздел 5.
